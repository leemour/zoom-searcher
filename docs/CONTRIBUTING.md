# Разработка

## Окружение

Нужен [uv](https://docs.astral.sh/uv/). Всё остальное он поставит сам.

```bash
git clone https://github.com/leemour/zoom-searcher
cd zoom-searcher
uv sync
uv run pre-commit install
```

Проверить, что всё живо:

```bash
uv run pytest
uv run ruff check .
uv run mypy src/
```

Те же действия через [Task](https://taskfile.dev/), если он у вас есть: `task --list` покажет
список, `task check` прогонит линтер, типы, тесты и поиск секретов.

Для задачи `secrets` нужен [gitleaks](https://github.com/gitleaks/gitleaks) в `PATH`. Хук
pre-commit ставит свою копию сам, так что отдельно gitleaks нужен только для `task secrets`.

Chrome нужен только для `ztx pull`. Тесты и поиск работают без браузера — `playwright`
подгружается внутри команды `pull`, а не при импорте.

## Никаких настоящих транскриптов

**В репозиторий не попадает ни одна настоящая расшифровка.** Ни файл, ни фрагмент, ни цитата
в тесте, ни тема встречи, ни имя участника, ни номер встречи Zoom, ни дата из вашего архива.
Это чужие персональные данные, а нередко ещё и коммерческая тайна. Репозиторий публичный,
и история коммитов не чистится.

Фикстуры **придумываются**: вымышленные имена, вымышленные темы, вымышленные номера встреч.
В репозитории уже есть подходящий состав — Иван Петров и Мария Сидорова из
`aliases.example.json`. Берите его, чтобы примеры были однородными и очевидно ненастоящими.

Как класть фикстуру:

- **По умолчанию — прямо в тест**, строкой в тройных кавычках. Кусок транскрипта на десяток
  строк читается на месте и не требует отдельного файла:

  ```python
  SAMPLE = """Встреча: Планёрка по релизу
  Дата: Mar 4, 2026 10:30 AM
  Zoom ID: 00000000000
  Говорят: Иван Петров, Мария Сидорова
  Реплик: 1

  ————————————————————————————————————————————————————————————

  [00:03:12] Иван Петров: Выкатываем в четверг, если тесты зелёные.
  """
  ```
- **Если файл всё-таки нужен**, назовите его `*.vtt.example` или `*.txt.example`. `.gitignore`
  отсекает `*.vtt` и `*.txt` по всему репозиторию — фикстура с обычным именем молча
  не попадёт в коммит, и тест упадёт у всех, кроме вас.

`.gitignore` и `gitleaks` — страховка от одной конкретной ошибки, а не разрешение не думать.

## Стиль

- Форматирование и линтер — `ruff`, настройки в `pyproject.toml`. Длина строки 110.
- Типы — `mypy` по `src/`. Новый код аннотируется.
- **Комментарии редко и только «почему».** Комментарий, пересказывающий строку кода, — это
  шум, который потом расходится с кодом. Пишите причину, ограничение или грабли, на которые
  наступит следующий читатель. В файлах, мимо которых вы просто проходите, чужие комментарии
  не трогайте.
- Тексты — по-русски, как в остальном репозитории. Это относится и к сообщениям об ошибках:
  они адресованы пользователю и должны говорить, что сделать дальше.

## Тесты

Покрывается то, что не зависит от Zoom: разбор WebVTT, склейка реплик, сборка и обратное
чтение `.txt`, морфология, отсев файлов, фильтры. `zoom.py` исключён из подсчёта покрытия
(`pyproject.toml`, `[tool.coverage.run] omit`) — его поведение определяет живой Zoom, и тест
на него был бы тестом на наши же моки.

```bash
uv run pytest              # покрытие печатается в терминал
task test-cov              # плюс HTML-отчёт в htmlcov/
```

Меняете `models.py` — правьте обе стороны сразу. Типы оттуда общие для скачивания и поиска,
и молчаливое расхождение между ними всплывёт не в тестах, а на живых данных.

## Коммиты

[Conventional commits](https://www.conventionalcommits.org/):

```
feat: фильтр по датам в search
fix: склейка реплик теряла последний кусок
docs: описание формата --json
test: разбор WebVTT без имени говорящего
refactor: отсев файлов вынесен из search
chore: обновление зависимостей
```

## Перед пул-реквестом

```bash
task format     # или uv run ruff format .
task check      # линтер, типы, тесты, секреты
```

`task check` формат **не проверяет**, а CI проверяет: в нём есть `ruff format --check .`.
Поэтому либо гоняйте `task format` руками, либо поставьте pre-commit — в нём есть хук
`ruff-format`, и он сделает это за вас.

CI на GitHub Actions гоняет gitleaks, ruff (линтер и формат), mypy и тесты на Python 3.11
и 3.13. Конфигурация — `.github/workflows/ci.yml`.
